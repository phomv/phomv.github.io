# Install

## Homebrew (macOS / Linux)

```sh
brew install phomv/tap/phomv
```

Or, equivalently:

```sh
brew tap phomv/tap
brew install phomv
```

The formula lives in [`phomv/homebrew-tap`](https://github.com/phomv/homebrew-tap)
and is regenerated by GoReleaser on every tagged release.

## Windows (winget)

```sh
winget install phomv.phomv
```

Manifests are published from
[`phomv/winget-pkgs`](https://github.com/phomv/winget-pkgs) (a fork of
`microsoft/winget-pkgs`) and merged into the official catalog via PR.

## Pre-built binaries

Grab the latest archive for your platform from the
[releases page](https://github.com/phomv/phomv/releases). Archives are built for
linux / darwin / windows on amd64 and arm64.

## From source

Install the latest tagged release with Go:

```sh
go install github.com/phomv/phomv/cmd/phomv@latest
```

Or build locally:

```sh
git clone https://github.com/phomv/phomv.git
cd phomv
make build       # produces ./bin/phomv
make install     # installs into $GOBIN
make release     # cross-compiles to ./dist for linux/macOS/windows
```

Requires Go **1.24+**.

## Verify

```sh
phomv version
```
